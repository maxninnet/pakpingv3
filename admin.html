⚙️ ระบบส่งออกและกู้คืนข้อมูล (Database Control)

หลังจากที่คุณแก้ไข เพิ่ม หรือลบข้อมูลข่าวสารในหน้าเว็บนี้จนพอใจแล้ว คุณสามารถดาวน์โหลดไฟล์ข้อมูลเพื่อเผยแพร่ให้ผู้ใช้อื่นเข้าถึงจากอุปกรณ์อื่นได้โดยทำตามคู่มือด้านล่าง

วิธีทำให้หน้าเว็บแสดงผลสำหรับทุกคน:
  1. กดปุ่ม "ดาวน์โหลด JSON" จะได้ไฟล์ชื่อ announcements_data.json
  2. คัดลอกไฟล์ดังกล่าวไปวางไว้ในโฟลเดอร์โครงการ (โฟลเดอร์เดียวกันกับ announcements.html)
  3. อัปโหลดขึ้นโฮสติ้งหลักของคุณ เมื่อผู้ใช้งานทั่วไปเข้ามาที่หน้าเว็บ ระบบจะดึงข้อมูลข่าวสารล่าสุดไปแสดงทันที!
เชื่อมต่อฐานข้อมูลคลาวด์ Supabase (ฟรี/ออนไลน์ทันที)

หากต้องการให้ข้อมูลแชร์ร่วมกันในทุกอุปกรณ์แบบสดๆ ผ่านคลาวด์ออนไลน์ (ไม่จำเป็นต้องคอยก๊อปปี้ไฟล์ JSON) คุณสามารถนำ Project URL และ API Key จากหน้าแดชบอร์ดของ Supabase มาผูกเข้ากับระบบหลังบ้านได้

* ระบบหลังบ้านและหน้าเว็บบอร์ดจะดึงข้อมูลแบบ Dynamic อัตโนมัติเมื่อกำหนดสองช่องนี้
